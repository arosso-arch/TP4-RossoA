# TP4 · Programación orientada a objetos en Java

Trabajo Práctico N.º 4 de Programación (Tecnicatura en Desarrollo de Software, ICOP): cinco sistemas pequeños para practicar **herencia, clases abstractas, interfaces y polimorfismo**.

## Ejercicios

| N.º | Sistema | Conceptos |
|---|---|---|
| 1 | Gestión académica | `Persona` → `Estudiante`, interfaz `Informable` |
| 2 | Vehículos | `Vehiculo` → `Auto` / `Moto`, interfaz `Mantenimiento` |
| 3 | Sistema bancario | `Cuenta` → `CajaAhorro`, interfaz `Auditable` |
| 4 | Gestión de empleados | `Empleado` → `Administrativo` / `Produccion`, interfaz `Calculable` |
| 5 | Préstamos bancarios | `Cliente` → `ClienteGeneral` / `Jubilado` / `ServicioPublico`, interfaz `PrestamoCalculable` |

## Tecnologías

Java · POO

## Cómo ejecutarlo

Abrí la carpeta en VS Code (con el Extension Pack for Java) o en otro IDE y ejecutá la clase `Principal`, que tiene un menú para correr cada ejercicio.
